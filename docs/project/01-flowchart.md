사용자가 사이트에서 이동하는 흐름과 주요 기능의 처리 흐름을 그림으로 정리했습니다.

## 1-1. 전체 서비스 흐름

```mermaid
flowchart TD
    A(["사용자 접속"]) --> B["메인 페이지 /"]
    B --> C{"로그인 상태?"}
    C -- "아니오" --> D["로그인 /member/login"]
    C -- "예" --> M["메인 · 헤더에 이름 표시"]

    D --> D1{"로그인 방식"}
    D1 -- "아이디/비밀번호" --> D2["BCrypt 비밀번호 검증"]
    D1 -- "카카오 · 네이버 · 구글" --> D3["OAuth2 소셜 로그인"]
    D1 -- "계정 없음" --> R["회원가입 /member/register"]
    R --> D
    D2 -- "성공" --> S["세션 loginUser 저장"]
    D2 -- "실패" --> D
    D3 --> S
    S --> M

    M --> F1["AI 실거래 단지 추천 /ai/recommend"]
    M --> F2["Q&A 게시판 /qna"]
    B --> F1
    B --> F2
    M --> L["로그아웃 /member/logout"] --> B
```

## 1-2. 회원가입 흐름 (4단계)

```mermaid
flowchart TD
    S1["1단계 약관 동의"] --> C1{"필수 약관 2개 동의?"}
    C1 -- "아니오" --> S1
    C1 -- "예" --> S2["2단계 이름 · 생년월일 · 성별"]
    S2 --> C2{"입력값 유효?"}
    C2 -- "아니오" --> S2
    C2 -- "예" --> S3["3단계 휴대폰 번호 입력"]
    S3 --> S3a["Firebase reCAPTCHA + SMS 발송"]
    S3a --> S3b["인증번호 6자리 입력 (3분 타이머)"]
    S3b --> C3{"인증 성공?"}
    C3 -- "아니오 · 시간 초과" --> S3a
    C3 -- "예 (firebaseUid 발급)" --> S4["4단계 아이디 · 비밀번호"]
    S4 --> API["POST /api/members/register"]
    API --> C4{"서버 검증"}
    C4 -- "형식 오류 400" --> S4
    C4 -- "아이디 중복 409" --> S4
    C4 -- "성공" --> DB[("member 테이블 저장 (BCrypt)")]
    DB --> E(["로그인 페이지로 이동"])
```

## 1-3. 소셜 로그인 흐름

```mermaid
flowchart TD
    A["소셜 로그인 버튼 클릭"] --> B["/oauth2/authorization/{kakao|naver|google}"]

    F -- "아니오" --> H["자동 회원가입 (아이디: 제공자_고유번호)"]
    G --> I["세션 loginUser 저장"]

    I --> J(["메인 페이지로 이동"])
```

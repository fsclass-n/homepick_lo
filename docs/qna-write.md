# Q&A 게시판 글쓰기

## 흐름

```
목록 [글쓰기] → (비로그인이면) 로그인 화면 → 로그인 후 글쓰기 화면으로 복귀
글쓰기 화면 → [등록하기] → 서버 입력 검사
  ├─ 오류: 입력값 유지 + 항목별 오류 메시지
  └─ 성공: DB 저장 → 목록 1페이지로 이동 + "질문이 등록되었습니다" 안내
```

## 화면

| 화면 | 내용 |
|---|---|
| 목록 (`/qna`) | 페이지 표시 옆 주황색 **글쓰기** 버튼 (비로그인은 자물쇠 아이콘), 등록 후 초록색 완료 안내 |
| 글쓰기 (`/qna/write`) | 목록과 같은 가운데 히어로 「질문 작성하기」, 작성자(로그인 회원 이름, 수정 불가), 제목·내용 입력과 글자 수, 개인정보 주의 안내, 취소 · 등록하기 |

## 규칙

| 항목 | 내용 |
|---|---|
| 로그인 | 화면(GET)과 등록(POST) 모두 로그인 확인. 비로그인은 로그인 후 글쓰기 화면으로 돌아옴 (일반 · 소셜 로그인 모두) |
| 작성자 | 입력받지 않고 **로그인한 회원 이름**으로 저장 (폼에 다른 이름을 넣어 보내도 무시) |
| 제목 | 필수, 앞뒤 공백 제거, 100자 이내 |
| 내용 | 필수, 앞뒤 공백 제거, 2,000자 이내 (줄바꿈은 1자로 계산 — 브라우저 글자 수와 동일) |
| 상태 · 작성일 | DB 기본값 `대기중`, 현재 시각 |
| 중복 등록 방지 | 등록 버튼 클릭 후 비활성화(「등록 중...」), 등록 후 목록으로 리다이렉트(새로고침해도 다시 저장되지 않음, PRG) |
| 보안 | SQL 은 `?` 바인딩, 화면 출력은 `th:text`(XSS 방지), 로그인 후 돌아갈 주소는 사이트 안 경로(`/...`)만 허용(오픈 리다이렉트 방지) |

검사는 브라우저(빈 칸 안내, 글자 수 제한)와 서버에서 두 번 합니다. 브라우저 검사를 우회해도 서버에서 막힙니다.

## 파일

| 파일 | 변경 |
|---|---|
| `controller/QnaController.java` | `GET /qna/write`, `POST /qna/write`, 목록에 로그인 정보 전달 |
| `service/QnaService.java` | `validate(title, content)`, `write(...)`, 제목·내용 최대 길이 |
| `repository/JdbcQnaRepository.java` | `insert(title, content, writer)` |
| `config/LoginRedirect.java` (신규) | 로그인 후 돌아갈 주소 저장 · 꺼내기 (안전한 경로만) |
| `controller/LoginController.java`, `config/OAuth2LoginSuccessHandler.java` | 로그인 성공 시 저장된 주소로 이동 (없으면 메인) |
| `templates/qna/write.html`, `static/js/qna-write.js` (신규) | 글쓰기 화면, 글자 수 · 빈 칸 안내 · 중복 클릭 방지 |
| `templates/qna/list.html`, `static/css/qna.css` | 글쓰기 버튼, 등록 완료 안내, 글쓰기 화면 스타일 |
| `src/test/.../QnaWriteTests.java` (신규) | 글쓰기 테스트 7개 |

## 검증 (`./gradlew test` 8개 통과)

| 테스트 | 확인 내용 |
|---|---|
| 비로그인 글쓰기 화면 | 로그인 화면으로 이동, 돌아올 주소 `/qna/write` 저장 |
| 로그인 글쓰기 화면 | 작성자 이름 표시, 헤더도 로그인 상태 |
| 빈 제목·내용 | 오류 메시지 2개, 저장 안 됨 |
| 제목 101자 | 오류, 입력값 유지 |
| 정상 등록 | 목록으로 이동 + 안내, 1건 증가, 제목 공백 제거, `\r\n` → `\n`, 작성자 = 로그인 회원(폼 값 무시), 상태 `대기중` |
| 비로그인 등록 요청 | 로그인으로 이동, 저장 안 됨 |
| 돌아갈 주소 검사 | `//evil.com`, `https://evil.com`, `/\evil.com` 등은 메인(/)으로 |

- 테스트는 `@Transactional` 로 실행 후 롤백 → 실제 DB 에 테스트 글이 남지 않음 (테스트 후에도 전체 24건 확인)
- 글쓰기 화면 · 오류 화면 · 목록 글쓰기 버튼을 화면 캡처로 확인

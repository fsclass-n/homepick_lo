# Firebase 휴대폰 인증 `auth/operation-not-allowed` (SMS 리전) 에러 정리

- 작업일: 2026-09-28
- 대상 파일: `src/main/resources/static/js/register.js`

## 증상

"인증문자 받기" 클릭 시 아래 에러 발생

```
Firebase: SMS unable to be sent until this region enabled by the app developer.
(auth/operation-not-allowed)
```

Firebase 콘솔 **승인된 도메인**(`localhost`, `127.0.0.1` 등)은 정상 등록되어 있음.

## 원인

이 에러는 **도메인 문제가 아니라 SMS 발송 정책 문제**다.
Firebase가 요청 번호를 **실제 SMS를 보내야 하는 번호**로 판단했고, 그 발송이 차단된 것.

1. **테스트 전화번호와 입력 번호가 정확히 일치하지 않음**
   - 테스트 번호로 등록된 번호는 SMS를 실제로 보내지 않으므로 리전 정책에 걸리지 않는다.
   - 에러가 났다는 것은 입력 번호가 테스트 번호 목록과 매칭되지 않았다는 뜻.
   - 코드는 입력값을 `+82` + (앞자리 0 제거) 형식으로 변환함
     - `01012345678` → `+821012345678`
   - 콘솔 **Authentication → 로그인 방법 → 전화 → 테스트용 전화번호** 에
     `+82 10-1234-5678` / `123456` 으로 등록되어 있어야 하며, 입력 번호 한 자리라도 다르면 실제 발송 경로로 넘어감.
2. **SMS 리전 정책에서 대한민국(KR)이 허용되지 않음**
   - 콘솔 **Authentication → 설정 → SMS 리전 정책** 에서 `허용` 선택 후 `대한민국(KR)` 추가 필요.
3. **Spark(무료) 요금제 제약**
   - 2024-09-01 이후 Spark 요금제는 **실제 SMS 발송 불가**. 실제 번호로 인증하려면 Blaze(유료) 업그레이드 필요.
   - 테스트 전화번호는 SMS를 보내지 않으므로 Spark에서도 사용 가능.

## 조치 방법 (콘솔)

| 목적 | 설정 위치 | 설정 값 |
|---|---|---|
| 테스트 번호로 개발 | Authentication → 로그인 방법 → 전화 → 테스트용 전화번호 | `+82 10-1234-5678` / `123456` |
| 실제 SMS 발송 | Authentication → 설정 → SMS 리전 정책 | 허용 → 대한민국(KR) |
| 실제 SMS 발송 | 요금제 | Blaze 업그레이드 |

> 입력란에는 `01012345678` (또는 `1012345678`)을 **정확히** 입력한다.

## 추가 확인 (테스트 번호를 정확히 등록·입력했는데도 에러가 나는 경우)

- 등록: `+82 10-1234-5678` / `123456`, 입력: `1012345678` → 변환값 `+821012345678` 로 **형식은 정상**.
- 그래도 에러가 나면 아래를 순서대로 확인한다.
  1. **테스트 번호 "저장" 여부**: `추가` 후 하단 `저장` 을 눌러야 반영됨. 창을 닫았다가 다시 열어 목록에 남아 있는지 확인.
  2. **SMS 리전 정책에 대한민국(KR) 허용**: Authentication → 설정 → SMS 리전 정책 → `허용` → `대한민국` 추가 후 저장.
     리전 검사가 테스트 번호 매칭보다 먼저 적용되는 사례가 보고되어 있음. 테스트 번호는 실제 SMS를 보내지 않으므로 Spark 요금제에서도 설정해도 비용 없음.
  3. **프로젝트 일치 여부**: 브라우저 개발자도구 콘솔에서 `firebase.app().options.projectId` 실행 → `homepick-80e34` 인지 확인.
     `firebase-config.js` 가 다른 프로젝트 값이면 그 프로젝트에는 테스트 번호가 없어 실제 발송으로 처리됨.
  4. 설정 변경 후 반영까지 수 분 걸릴 수 있으므로 잠시 후 **강력 새로고침(Ctrl+Shift+R)** 하고 재시도.

## Spark(무료) 요금제 SMS 무료 제공 여부

- 예전에는 Spark 요금제에서 **하루 10건** SMS가 무료였음.
- **2024-09-01부터 정책 변경**: 공식 문서(Authentication → Usage and limits)에 "Verification code SMS messages: **Pay as you go (Blaze) plan only**" 로 명시됨.
  → 현재 Spark 요금제에서는 **실제 SMS 발송 불가**, 테스트 전화번호만 사용 가능.
- 실제 번호로 인증하려면 Blaze 업그레이드 + SMS 리전 정책 KR 허용이 필요하며, SMS는 건당 과금됨.

## 코드 수정 내용 (`register.js`)

인증문자 발송 실패 시 Firebase 원문 영어 메시지 대신 에러 코드별 한글 안내를 표시하도록 개선.

| 에러 코드 | 안내 문구 |
|---|---|
| `auth/operation-not-allowed` | SMS 발송이 허용되지 않은 번호/지역 (SMS 리전 정책·테스트 번호 확인) |
| `auth/invalid-phone-number` | 올바르지 않은 휴대폰 번호 형식 |
| `auth/too-many-requests` | 요청 과다, 잠시 후 재시도 |
| `auth/quota-exceeded` | SMS 발송 한도 초과 |
| `auth/billing-not-enabled` | 실제 SMS 발송은 Blaze 요금제에서만 가능 |

매핑되지 않은 코드는 기존처럼 `err.message` 를 그대로 표시.

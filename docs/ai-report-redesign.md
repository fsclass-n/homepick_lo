## 1. 문구 수정: 매물 → 실거래 단지

데이터가 **현재 판매 중인 매물이 아니라 이미 거래가 완료된 실거래 신고 기록**이므로 오해가 없도록 변경.

| 위치 | 변경 전 | 변경 후 |
|---|---|---|
| 페이지 제목·히어로·헤더 메뉴 | AI 맞춤 매물 추천 | **AI 실거래 단지 추천** |
| 히어로 설명 | AI가 최적의 매물을 추천 | 국토교통부 실거래 데이터를 AI가 학습해, 조건에 맞는 단지를 **거래 기록으로** 찾아드림 |
| 히어로 안내 배지 | - | "현재 판매 중인 매물이 아닌, 거래가 완료된 실거래 기록 기준입니다" |
| 조건 입력 | 최대 예산 / 희망 방 수 | 최대 예산 **(실거래가 기준)** / 희망 방 수 **(전용면적으로 추정)** + "최근 6개월 실제 거래 가격 기준" 설명 |
| 버튼·로딩 | AI 추천 받기 / AI가 매물을 분석 중 | **AI 단지 추천 받기** / AI가 실거래 단지를 분석 중 |
| 결과 제목 | AI 추천 결과 N개 중 상위 6개 | **AI 추천 단지** · 조건에 맞는 거래 단지 N곳 중 상위 6곳 |
| 카드 가격 | (라벨 없음) | **실거래 중위가 (거래 n건)**, 최근 거래일 |
| 카드 배지·분석 | AI 저평가 / 예측 적정가보다 N% 낮게 | **저평가 거래** / AI 적정 거래가보다 N% 낮은 가격에 거래 |
| AI 안내 문장 | ...분석해 추천한 것입니다 | ...추천한 단지입니다. 가격은 **이미 거래가 완료된 실거래가**이며 매물 호가와 다를 수 있음 |
| 인사이트 | AI 저평가 단지 TOP 5 / N% 저렴 | **AI 저평가 거래 단지 TOP 5** / N% 낮게 거래 |
| KPI | AI 저평가 단지 비율 / AI 적정가 예측력 | 저평가 거래 단지 비율 / AI 적정 거래가 예측력 |
| 결과 없음 | 거래 데이터가 없습니다 / 최저 거래가 | 실거래 기록이 없습니다 / 최저 **실거래가** |
| 하단 고지 | 실제 매물 가격과 다를 수 있음 | 실거래 신고 자료(거래 완료 기록) 기반, **매물 호가와 다를 수 있으며 투자 판단 근거로 사용할 수 없음** |

## 2. 디자인: 'AI 실거래 분석 리포트'로 그룹화

기존에는 추천 결과와 시장 인사이트가 페이지 아래로 따로 나열되어 있었음 → **하나의 리포트 카드 + 탭**으로 묶음.

```
┌ AI 실거래 분석 리포트 ──────────────────── [추천 단지 ⑥] [시장 인사이트] ┐  ← 딥 블루 그라데이션 헤더
│  AI ANALYSIS REPORT                                                            │     (히어로와 같은 톤)
│  수도권 실거래 128,339건 학습 · 계약일 2026-04-01 ~ 2026-09-30 · 기준 시각     │
├────────────────────────────────────────────────────────────────────────────────┤
│  (탭 내용) 추천 단지 카드  또는  시·도 탭 + KPI + 차트 + 유형 + TOP 5             │  ← 연한 회청색 본문
├────────────────────────────────────────────────────────────────────────────────┤
│  🛡 실거래 신고 자료 기반 참고 정보 고지                                          │
└────────────────────────────────────────────────────────────────────────────────┘
```

- **세그먼트 탭**: 헤더 우측 알약형 탭, 선택된 탭은 흰 배경 + 그림자
- **동작**
  - 처음 접속: '시장 인사이트' 탭 표시 (추천 전에도 볼 수 있는 내용)
  - 'AI 단지 추천 받기' 클릭 → '추천 단지' 탭으로 자동 전환, 탭에 추천 개수 배지(주황), 리포트 위치로 부드럽게 스크롤
  - 동시에 인사이트도 검색 지역 기준으로 갱신 (예: 분당구 → 경기 탭, 분당구 강조)
- 추천 전 '추천 단지' 탭: 아이콘 + "아직 추천을 받지 않았어요" 안내
- 리포트 기준 정보(학습 건수·계약 기간·기준 시각)를 헤더 한 곳으로 통합
- 모바일: 탭이 가로 전체 폭으로 균등 분할, 여백 축소

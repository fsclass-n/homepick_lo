# AI 실거래 분석 리포트: 카드형 → 문서형(에디토리얼) 레이아웃으로 전환

- 작업일: 2026-10-07
- 대상 파일
  - `src/main/resources/templates/sub/ai-recommend.html` (인사이트 마크업)
  - `src/main/resources/static/js/ai-recommend.js` (추천 단지 → 순위 행)
  - `src/main/resources/static/js/ai-insights.js` (지표 스트립, 유형 행, TOP 5 행)
  - `src/main/resources/static/css/ai-recommend.css` (9장 추가)

## 문제

리포트 안에 테두리·그림자가 있는 카드(추천 6장, 인사이트 패널 5개, KPI 4개, 유형 8장)가 겹겹이 나열되어
'카드 속 카드' 구조가 되고, 페이지 전체(히어로·입력 카드·리포트)와 톤이 어울리지 않았음.

## 바꾼 방향: 한 장의 분석 보고서처럼

| 요소 | 변경 전 | 변경 후 |
|---|---|---|
| 리포트 본문 | 회청색 바탕 위 흰 카드들 | **흰 바탕 한 장**, 섹션은 가는 구분선으로만 구분 |
| 섹션 제목 | 카드마다 제목 | **번호 섹션** `01 시장 요약` ~ `06 저평가 TOP 5` (번호는 주황 포인트) |
| 분석 범위 탭 | 알약 버튼 | **밑줄형 텍스트 탭** (분석 범위 라벨 + 수도권 전체/서울/인천/경기) |
| 핵심 지표 | 박스 4개 | **지표 스트립**: 큰 숫자 + 세로 구분선 |
| 월별 추이 / 가격 결정 요인 | 카드 2개 | 7:5 **두 단 + 가운데 세로선** |
| 해석 문장 | 파란 배경 박스 | **왼쪽 강조선** 인용문 형태 |
| 단지 유형 | 카드 8장 그리드 | **표 형태 행**: 유형·설명 / 중위 거래가 / 전용·연식 / 단지 비중 막대·주요 지역. 예산 OK 행은 왼쪽 파란 선 + 은은한 배경 |
| 추천 단지 | 카드 6장 | **순위 리스트**: 큰 번호(01~03 파랑, 04~ 회색) / 단지명·위치·스펙·AI 분석 / 실거래 중위가·AI 적정 거래가 / 조건 매칭 점수 + 미터 |
| 저평가 TOP 5 | 작은 목록 | 추천 단지와 **같은 순위 행** 디자인, 오른쪽에 '적정가 대비 -N%' + 주황 미터 |
| 빈 상태·결과 없음 | 점선 박스 | 위아래 구분선 + 여백 |
| 하단 고지 | 흰 띠 | 연한 회청색 띠로 본문과 구분 |

- 리스트 상단은 굵은 선(2px)으로 시작해 표(테이블)처럼 읽히게 함
- 공통 요소 정리: `.ai-tag`(작은 라벨), `.ai-rank-label`(항목명), `.ai-meter`(가는 진행 막대)

## 반응형

- 데스크톱: 순위 행 4열(번호 / 정보 / 가격 / 점수), 유형 행 4열, 지표 4개 한 줄
- 모바일: 순위 행은 번호 + 정보, 그 아래 **가격과 점수를 한 줄에 나란히**, 유형 행은 세로 쌓기, 지표 2×2
- 추천 후 자동 스크롤 시 상단 고정 헤더(70px)에 리포트 머리가 가리지 않도록 `scroll-margin-top: 90px`

- 18080 포트 서버 + 헤드리스 Chrome(DevTools Protocol)으로 실제 클릭 흐름 캡처
  - 첫 화면(시장 인사이트), 분당구·3방·13억 추천 후(추천 단지 6곳), 모바일 430px
- JS 문법 검사 통과

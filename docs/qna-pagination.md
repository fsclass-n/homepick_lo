# Q&A 게시판 페이지네이션 · 가운데 제목

## 변경 내용

1. **제목을 가운데로**: AI 실거래 단지 추천 페이지와 같은 딥 블루 그라데이션 히어로(아이콘 · 제목 · 설명)를 상단에 두고, 목록 카드가 히어로 위로 살짝 겹쳐 올라오게 했습니다.
2. **한 페이지 10개**: DB 에서 `LIMIT 10 OFFSET n` 으로 필요한 10개만 조회합니다(전체를 읽어 자르지 않음).
3. **페이지 이동 버튼**: `맨 앞 · 이전 · 페이지 번호(최대 5개) · 다음 · 맨 뒤`
   - 현재 페이지는 파란색으로 강조, 첫 페이지에서는 맨 앞·이전, 마지막 페이지에서는 다음·맨 뒤가 비활성
   - 페이지 번호는 현재 페이지가 가운데 오도록 표시 (예: 7페이지 → 5~9)
   - 모바일(576px 미만)에서는 버튼 글자를 숨기고 화살표 아이콘만 표시
4. 목록 위에 `전체 N건`, `현재 / 전체 페이지` 표시

## 주소

| 주소 | 동작 |
|---|---|
| `/qna` | 1페이지 |
| `/qna?page=2` | 2페이지 |
| `/qna?page=999`, `/qna?page=-3` | 범위를 벗어나면 마지막 / 첫 페이지로 |
| `/qna?page=abc` | 숫자가 아니면 1페이지 (400 오류 대신) |

## 수정한 파일

| 파일 | 변경 |
|---|---|
| `repository/JdbcQnaRepository.java` | `findAll()` → `count()`, `findPage(limit, offset)` |
| `service/QnaService.java` | `getQnaPage(page)`: 페이지 크기 10, 번호 5개, 범위 보정 |
| `dto/QnaPage.java` (신규) | 목록 + 현재/전체 페이지 + 번호 범위, `hasPrev()`/`hasNext()` |
| `controller/QnaController.java` | `page` 파라미터 처리, `qnaPage` 를 화면에 전달 |
| `templates/qna/list.html` | 가운데 히어로, 건수 표시, 페이지네이션 |
| `static/css/qna.css` (신규) | 히어로 · 목록 카드 · 페이지네이션 스타일 |

## 검증

- 현재 글 24건 → 3페이지 (10 / 10 / 4건)
- 1페이지: 맨 앞·이전 비활성, 3페이지: 다음·맨 뒤 비활성, 현재 번호 강조 확인 (화면 캡처)
- `page=999` → 3페이지, `page=-3` → 1페이지, `page=abc` → 1페이지

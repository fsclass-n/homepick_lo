# AI 실거래 단지 추천: 둥근 카드 레이아웃 → 전체 폭 밴드 + 직선 레이아웃

- 작업일: 2026-10-07
- 대상 파일
  - `src/main/resources/templates/sub/ai-recommend.html`
  - `src/main/resources/static/css/ai-recommend.css` (10장 추가)

## 변경 전 문제

- 히어로 위로 떠 있는 **둥근 입력 카드**, 그 아래 **둥근 리포트 카드**(최대 폭 1080px)가 페이지 중앙에 떠 있는 구조
- 버튼·입력칸·탭·배지가 모두 둥근 모서리(알약/라운드)라 사이트의 다른 영역(헤더·푸터: 직선 띠)과 어울리지 않음

## 변경 후 구조: 위에서 아래로 이어지는 전체 폭 밴드

```
[헤더]           메인 블루 띠 (기존)
[1 히어로]       딥 블루 그라데이션 띠 — 제목·설명·실거래 기준 안내
[2 검색 밴드]    흰 띠 (상단 4px 파란 선) — 예산 | 방 수 | 지역 | [AI 단지 추천 받기] 한 줄 검색 바
                 아래: 학습 데이터 정보 · 재학습 버튼 · 진행 표시
[3 리포트 헤더]  딥 블루 그라데이션 띠 — AI ANALYSIS REPORT / 제목 / 기준 정보
                 오른쪽 아래에 직사각형 탭 [추천 단지 ⑥][시장 인사이트] (선택 탭은 흰색 + 위쪽 주황 선, 본문과 이어짐)
[3 리포트 본문]  흰 띠 — 번호 섹션(01~06) / 순위 리스트 (이전 작업의 문서형 레이아웃 유지)
[고지 밴드]      연한 회청색 띠
[푸터]           (기존)
```

- 각 밴드는 화면 전체 폭, 내용은 사이트 공통 `container` 폭에 정렬 → 헤더·푸터와 같은 그리드
- 입력 카드가 히어로에 겹쳐 올라오던 음수 여백 제거

## 직선화한 요소

- 입력칸·선택칸·추천 버튼·재학습 버튼, 히어로 안내 배지, 진행 패널·단계 칩·진행 막대
- 리포트 탭·추천 개수 배지·태그·미터·막대 그래프·시군구 강조 행·범위 탭 밑줄
- 데스크톱 검색 바: 입력칸을 이어 붙여(사이 테두리 제거) 하나의 막대처럼 표시, 버튼도 같은 높이(46px)
- 버튼 그라데이션·떠오르는 그림자 효과 제거 → 단색(메인 블루), 호버 시 진한 블루

## 반응형

- 992px 이상: 검색 바 4칸 한 줄, 리포트 탭은 헤더 오른쪽 아래
- 768~991px: 입력 2열, 탭은 전체 폭 2등분
- 767px 이하: 입력 세로 쌓기, 탭 전체 폭 2등분

## 검증

- 18080 포트 서버 + 헤드리스 Chrome(DevTools Protocol)으로 첫 화면(시장 인사이트), 분당구 추천 결과, 모바일 430px 캡처 확인

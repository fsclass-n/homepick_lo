## 2. 학습 변경 (`04_train.py`)

- 지역 키를 `시도 + 시군구`(예: `경기 성남시 분당구`)로 변경 → 다른 시·도의 같은 이름 구가 섞이지 않음
- RandomForest 지역 One-Hot 도 이 키 기준, 가격 결정 요인 이름은 `지역(시·군·구)`
- `insights.scopes`: **수도권 전체 + 서울·인천·경기** 각각의 거래 수·단지 수·중위가·평당가·저평가 비율·월별 추이
- `insights.bySgg`: 시·도 포함 82개 시·군·구 (옹진군은 해당 기간 거래 없음)

## 3. 화면 변경 (`ai-insights.js`)

- **시·도 탭**: 수도권 전체 / 서울 / 인천 / 경기 → 핵심 지표·월별 추이·시군구 순위·단지 유형·저평가 TOP 이 선택 범위로 바뀜
- **검색과 연동**: 'AI 추천 받기' 시 지역에 맞는 탭 자동 선택
  - `분당구` → 경기 탭, 성남시 분당구 강조 "경기 47개 시·군·구 중 평당가 2위"
  - `인천 연수구` → 인천 탭 "인천 10개 시·군·구 중 1위"
- 수도권 전체 보기에서는 시·군·구 순위를 상위 20곳만 표시 (내 지역은 순위 밖이어도 추가 표시)
- 단지 유형(KMeans)은 선택 범위의 단지로 다시 집계 (개수·중위가·주요 지역)
- 문구에서 '서울' 고정 표현 제거 → 선택 범위 이름 사용
- 지역 입력 안내: `서울·인천·경기 (예: 분당구)`, 지원 지역이 아니면 수도권만 지원한다고 안내

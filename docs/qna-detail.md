# Q&A 게시판 상세 보기

## 화면 (`/qna/{번호}`, 누구나)

| 영역 | 내용 |
|---|---|
| 상단 | 목록과 같은 가운데 히어로 「Q&A 게시판」 |
| 제목부 | `No. 번호` · 상태 배지(대기중/답변완료), 제목, 작성자 · 작성일 |
| 본문 | 작성한 **줄바꿈 그대로** 표시, 긴 URL 도 카드 밖으로 넘치지 않음 |
| 답변 안내 | 대기중: 「답변을 준비하고 있어요…」, 답변완료: 「답변이 완료된 질문입니다」 (답변 저장 기능은 아직 없음) |
| 이전 · 다음 글 | 다음 글 = 바로 위 번호(더 최근), 이전 글 = 바로 아래 번호(더 오래된), 없으면 「…없습니다」 |
| 버튼 | **목록**(보던 페이지 · 검색 결과로 복귀), **글쓰기** |

목록에서 제목을 누르면 상세 보기로 이동합니다(마우스를 올리면 파란색 밑줄).

## 목록으로 돌아가기

목록의 제목 링크에 현재 페이지와 검색 조건을 붙여 상세 보기로 넘기고, [목록] · 이전/다음 글 링크가 그대로 이어받습니다.

```
/qna?page=2&type=title&keyword=전세   (목록 2페이지, 제목 '전세' 검색)
  → /qna/18?page=2&type=title&keyword=전세   (상세)
  → [목록] /qna?page=2&type=title&keyword=전세   (같은 화면으로 복귀)
```

이전 · 다음 글은 검색과 관계없이 **전체 글의 번호 순서**로 이동합니다.

## 예외 처리

| 경우 | 동작 |
|---|---|
| 없는 번호 (`/qna/999999`) | 목록으로 이동 + 주황색 안내 「삭제되었거나 존재하지 않는 글입니다.」 |
| 숫자가 아닌 주소 (`/qna/abc`) | 404 |
| `/qna/write` | 상세 보기와 겹치지 않고 글쓰기로 동작 (상세 주소는 숫자만 허용) |
| 본문 · 제목의 HTML 태그 | `th:text` 로 글자로만 출력 (스크립트 실행 안 됨) |
| 잘못된 검색 종류 · 페이지 값 | 제목+내용 · 1페이지로 보정 |

## 파일

| 파일 | 변경 |

| `controller/QnaController.java` | `GET /qna/{id}`, 목록에 `listQuery`(페이지+검색 조건) 전달, 공통 메서드 `parsePage`, `searchQuery` |
| `service/QnaService.java` | `getQna`, `getPrev`, `getNext` |
| `repository/JdbcQnaRepository.java` | `findById`, `findPrev`, `findNext` |

| `static/css/qna.css` | 상세 화면 · 제목 링크 · 주황 안내 스타일 |
| `src/test/.../QnaDetailTests.java` (신규) | 상세 보기 테스트 7개 |

## 검증 (`./gradlew test` 15개 통과)

| 테스트 | 확인 내용 |
|---|---|
| 본문 표시 | 제목 · 작성자 · 번호 · 상태, 줄바꿈 유지, `<b>` · `<script>` 는 글자로 출력 |
| 이전 · 다음 글 | 가운데 글에서 위 · 아래 번호 링크, 가장 최근 글은 「다음 글이 없습니다」 |
| 목록 복귀 | `page=2&type=title&keyword=전세` 유지, 잘못된 type 은 all |
| 목록 제목 링크 | `?page=1`, 검색 중이면 검색 조건 포함 |
| 없는 글 · 숫자 아닌 주소 · 글쓰기 주소 | 목록 + 안내 / 404 / 글쓰기(로그인 이동) |

- 테스트용 글은 `@Transactional` 롤백으로 실제 DB 에 남지 않음
- 로컬 서버(8081)에서 `/qna/18` 화면 캡처 확인, 없는 번호는 302 → `/qna`

# Q&A 게시판 검색 기능

## 화면

- 상단 제목 아래 가운데에 검색 바: **검색 종류(제목+내용 · 제목 · 내용 · 작성자) + 검색어 + 검색 버튼**
- 검색하면 목록 위에 `'전세' 검색 결과 8건 · 검색 해제` 표시
- 결과가 없으면 `'검색어'에 대한 검색 결과가 없습니다.` + 전체 목록 보기 링크
- 검색 후에도 검색창에 검색어와 검색 종류가 그대로 유지
- **페이지네이션과 함께 동작**: 검색 결과도 10개씩 나뉘고, 맨 앞 · 이전 · 번호 · 다음 · 맨 뒤 링크가 검색 조건을 유지

## 주소

| 주소 | 동작 |
|---|---|
| `/qna?keyword=전세` | 제목+내용에서 '전세' 검색 (type 생략 시 all) |
| `/qna?type=title&keyword=아파트&page=2` | 제목 검색 결과의 2페이지 |
| `type` | `all`(제목+내용) · `title` · `content` · `writer` |

## 처리 방식

| 항목 | 내용 |
|---|---|
| 검색 방식 | SQL `LIKE '%검색어%'` (부분 일치), 건수와 목록 모두 같은 조건으로 조회 → 페이지 수도 검색 결과 기준 |
| SQL 주입 방지 | 검색어는 `?` 바인딩, 검색 종류는 정해진 4개 값만 허용(그 외는 제목+내용) |
| 특수문자 | `%`, `_`, `\` 는 이스케이프해서 글자 그대로 검색 (예: `%` 검색이 전체 글을 반환하지 않음) |
| 검색어 정리 | 앞뒤 공백 제거, 최대 50자 |
| 화면 출력 | Thymeleaf `th:text` 로 출력해 `<script>` 같은 입력도 글자로만 표시(XSS 방지) |
| 페이지 링크 | 검색 중일 때만 `&type=..&keyword=..`(URL 인코딩)를 붙임 |

## 수정한 파일

| 파일 | 변경 |
|---|---|
| `repository/JdbcQnaRepository.java` | `count(type, keyword)`, `findPage(type, keyword, limit, offset)` + 검색 조건(WHERE) 생성 |
| `service/QnaService.java` | 검색 종류·검색어 정리(`normalizeType`, `normalizeKeyword`), `getQnaPage(page, type, keyword)` |
| `controller/QnaController.java` | `type`, `keyword` 파라미터, 페이지 링크용 `searchQuery` |
| `templates/qna/list.html` | 검색 바, 검색 결과 건수 · 해제, 결과 없음 안내, 링크에 검색 조건 유지 |
| `static/css/qna.css` | 검색 바 스타일(모바일 대응) |

## 검증

| 검색 | 결과 |
|---|---|
| 검색 없음 | 24건, 3페이지 |
| 제목+내용 '전세' | 8건 |
| 제목 '아파트' | 10건 (1페이지) |
| 내용 '대출' | 3건 |
| 작성자 'user' | 3건 |
| 'zzzqqq', `%`, `_`, `' OR '1'='1` | 0건 + 안내 문구 (특수문자·SQL 문자열이 조건으로 해석되지 않음) |
| 잘못된 type + 앞뒤 공백 `'  전세  '` | 제목+내용 '전세' 와 같은 8건 |
| `<script>alert(1)</script>` | 화면에 글자로만 출력 |

- 검색 중 페이지 링크에 검색 조건 유지, 검색하지 않을 때는 `?page=N` 만 붙음
